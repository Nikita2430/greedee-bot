# Greedee World AI Stylist Bot

Telegram bot that creates stylish collages from user photos and analyzes color palettes.

## Features
- Creates dark-themed collages with watermark
- Analyzes dominant colors in photos
- Provides style tips based on color harmony
- Directs traffic to greedee.ru and @greedeeworld channel

## Tech Stack
- Python 3
- aiogram 3.x
- Pillow
- colorthief
- python-dotenv

## Setup
1. Clone repository
2. Install dependencies: `pip install -r requirements.txt`
3. Create `.env` file with `BOT_TOKEN=your_token_here`
4. Run: `python3 main.py`
